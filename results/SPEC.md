### 1. Requirement
  Пользователь не должен иметь возможности изменить название задачи на пустое, то есть состоящее из пробельных символов: пробела, табуляции, неразрывного пробела U+00A0 и нулевого пробела U+200B. Если название задачи было изменено на пустое, то изменения не должны быть сохраненны.
  Вместо этого нужно показать «Название не может быть пустым».


### 2. Acceptance tests
  Тесты которые должны проходить.
  * R1: Изменение на пустое имя не должно сохраняться. Вместо этого должно вывестись «Название не может быть пустым».
  * R2: Унаследованная задача с пустым названием не отображается в списках задач.
  * R3: Счетчик задач считает только задачи с непустым названием.

### 3. Non-goals
  * Мы не меняем остальную структуру приложения.

### 4. Files in scope 
  * src/tasks.ts 
  * src/App.tsx.

### 5. Definition of done
  Все тесты должны проходить и все должно без ошибок собираться.
